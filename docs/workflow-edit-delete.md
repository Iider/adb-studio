# 工作流编辑与删除

任务卡片“编辑”打开关联画布。编辑器自动保存草稿；手动“保存”检查参数、连线和标注后覆盖可运行内容。已启动运行保留原内容。

工作流任务必须保留关联草稿。编辑器只允许删除未保存为任务的草稿；已保存任务从任务卡片“更多 → 删除任务”整体删除。

删除范围：任务本体、草稿、定时、全部执行记录（含本机归档）、事件、运行判断与运行截图。运行、等待、恢复、暂停或仍在结束的任务须先停止并等到结束。其他任务、手机信息及独立识别检查不受影响。

数据库记录在同一事务删除，失败回退；截图清单同时写入。截图暂时无法清理时返回 `cleanup_pending: true`，后台约每 30 秒和启动时重试。未确认截图清理完成前不报告全部完成。

接口与文件操作见[工作流说明](workflows.md)。旧无画布编辑页、旧本体提交接口、内置预置与恢复功能均已移除。
