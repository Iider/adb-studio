# 工作流导出与任务管理

日期：2026-10-28。用户验收通过后，已部署到本地正式工作台 `http://127.0.0.1:17841`。

## 功能

- 卡片导出工作流，编排器导出当前草稿；保留布局、坐标与引用的 PNG 样本。导入副本与覆盖导入仍待开发，见[开发方案](../workflow-import-export.md)。
- 删除任务同时清除草稿、定时、全部执行记录、判断结果与运行截图；截图清理失败时持久保存待清理项并重试。旧页面不能重新保存已删除任务，见[编辑与删除](../workflow-edit-delete.md)。
- “新建工作流”始终打开独立空白画布；卡片“编辑”才打开已有任务。首次保存创建独立任务，不覆盖原任务。
