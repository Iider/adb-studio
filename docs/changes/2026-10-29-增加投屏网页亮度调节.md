# 增加投屏网页亮度调节

状态：用户验收通过；正式服务 17841 尚未更新，待部署。

## 需求

调节投屏后在网页中呈现的手机画面亮度，不修改手机实际亮度。

## 方案与关键决策

仅对网页画布和最近截图预览应用 CSS 亮度滤镜，不发送手机亮度指令。这样可即时调整显示，同时保留手机状态、截图原文件与识别输入。

画面下方提供“网页亮度”滑块，范围 20%–150%，步长 5%，默认 100%；“恢复”按钮回到默认值。保存在当前浏览器，切换手机和刷新后保持；浏览器禁用存储时仍可调节当前画面。全屏时保留调节入口，为底部控件预留高度。

未采用手机系统亮度设置，因为它会改变实体屏幕，与需求不符；未调整视频解码或原始图像，因为本次只需改变网页显示。

## 改动内容

- `web/src/lib/components/LiveScreen.svelte`：亮度控件、浏览器保存与读取、画布和截图预览滤镜。
- `web/src/app.css`：紧凑横排控件、窄屏换行、全屏画面高度。
- `docs/ui-components.md`：使用范围与保存方式；`AGENTS.md`：验收与待部署状态；`CHANGELOG.md`：变更索引。
