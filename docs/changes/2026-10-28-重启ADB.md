# 重启 ADB 并重连

入口：添加局域网设备 → 连接异常？重启 ADB → 重启 ADB 并重连。

重启整个电脑的 ADB 服务，扫描并尝试重连已登记手机，显示在线与离线结果。有任何未结束任务时拒绝重启。Mac 默认使用 libusb，已有 `ADB_LIBUSB` 设置优先。
