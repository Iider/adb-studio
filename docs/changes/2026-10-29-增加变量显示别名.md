# 增加变量显示别名

状态：用户验收通过，已部署至 Windows 本地正式工作台 17841。

用户要求运行参数显示用途说明，例如“点击次数”“点击间隔（秒）”，避免只显示 count、interval。

变量定义增加可选 `alias`，最多 40 字。运行表单、参数记录、画布摘要与参数错误优先使用别名；空白或未填写时显示变量名称。引用选择同时显示别名和名称，避免同名显示项难以区分。编号、默认值、单位及执行规则不变，不改写现有工作流。

编辑器、设备页与任务详情复用显示规则；草稿、保存本体、导入导出与运行快照保留别名。字段说明见[工作流接口](../workflows.md#运行变量)。

运行参数输入框宽 180px，宽屏并排、窄屏换行。按用户反馈移除外框、留空提示、默认值与范围说明、全部恢复默认按钮，默认值直接回显到输入框；保留字段错误和用户填写的变量说明。预览曾验证宽屏两列、390px 窄屏单列，参数区域无横向溢出。

验证：37 项 Rust 测试、13 项前端编辑器测试、网页类型检查与构建、工作流导入导出检查通过。浏览器验证别名显示、编辑保存、刷新保留及名称与别名分开；预览使用模拟手机，未操作真实手机。

精简表单后，网页检查、构建与 13 项编辑器测试通过；浏览器确认默认值 10／5 直接显示、可改为 20／0、非法小数提示整数错误并禁用运行，刷新恢复默认值。未启动手机任务。

验收预览使用模拟手机，示例变量 count／interval 的显示别名分别为点击次数／点击间隔，后者单独配置秒单位。截图保存在本机 `data/verification/input-alias-runtime.png`，不提交。
