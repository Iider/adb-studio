# 移除旧任务

## 需求与决策

用户要求不再兼容旧任务，只使用工作流创建的任务。

只保留画布编辑器创建与导入的工作流。删除内置任务、旧动作执行与专用参数、无画布编辑页、旧任务源文件；关闭裸本体提交与导入。不把旧任务转换到新画布，避免保留两套配置与执行规则。

## 改动

- `src/engine.rs`、`src/types.rs`、`src/main.rs`：只保留画布执行，不再预置内置任务。
- `src/legacy_cleanup.rs`、`src/db.rs`：读取原始记录，备份后清理旧任务及其关联数据，失败回退。
- `src/api.rs`、`src/drafts.rs`、导入模块：关闭旧入口，已保存任务必须保留关联草稿。
- 任务页、定时页与编辑器：统一从画布编辑；去掉旧专用参数及普通任务编辑页。
- 模拟检查与说明文档：改用编辑器工作流；模型整改方案只覆盖画布文字条件。
- `Dockerfile`：去掉已删除的旧任务目录引用；模拟检查阶段复制已构建网页，使网页入口检查使用本轮内容。

保留：编辑器点击、滑动、按键、等待、条件、循环、定时、暂停／继续、同机互斥、身份与屏幕检查、独立模型看图检查。

数据：旧任务及关联定时、运行、事件在启动时清理，先生成本地 SQLite 备份；编辑器任务、草稿、手机与设置保留。关联已保存任务的草稿不能单独删除。
