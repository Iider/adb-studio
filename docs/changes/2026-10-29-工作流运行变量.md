# 工作流运行变量

状态：已部署本机工作台；用户已确认提交与推送。日期：2026-10-29。

## 使用

1. 打开工作流，选中“开始”，添加变量并设置名称、类型和默认值。
2. 在循环、点击、滑动或等待节点的数值字段选择“使用变量”。
3. 在编辑器运行设置、设备页“直接运行”或任务详情填写本次参数；留空用默认值。

最多 20 个变量，支持整数与小数、选填单位及范围、重命名与排序。同一变量可供多个节点引用。临时值不修改工作流；运行记录保留本次值，暂停、断线和后台重启后继续使用。定时执行使用当前保存的默认值。

接口及文件格式见[工作流说明](../workflows.md#运行变量)。
