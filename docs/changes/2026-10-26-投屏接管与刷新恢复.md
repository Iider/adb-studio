# 投屏接管与刷新恢复

## 问题与行为

旧连接占用同一手机时，新页面只能收到“请先关闭原投屏”的提示，无法直接接管；刷新页面后还需重新点击开启。

开启投屏会取消旧会话，等待旧触点、操作权和通道释放后再建立新会话。连接过程中连续接管时，以最后一次请求为准。旧页清除画面与恢复记录，显示“在此投屏”入口。

当前页签记录已开启的手机，刷新后恢复一次。主动停止、离开设备页、切换手机、异常断线或被接管后清除记录。新页签不会自动接管，投屏恢复不改变执行任务的运行或暂停状态。完整用法见 [实时投屏](../realtime-screen.md#页面接管与刷新)。
