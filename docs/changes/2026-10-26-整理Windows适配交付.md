# 整理 Windows 适配交付

## 需求

维护 Windows 适配文档，做本地提交并推送到远端。

## 方案与关键决策

Windows 适配作为一个功能单位提交，包含平台代码、安装工具、模拟检查与使用说明。用户明确要求提交与推送，按此要求交付；真机尚未完成的验收继续保留，不将模拟检查视为真机通过。

## 改动

- 部署说明补充已安装后台的快捷方式启动方法，列出实际验证范围。
- `AGENTS.md` 清除过期的待提交状态，保留真机与跨平台回归待办。
- `CHANGELOG.md` 添加本次交付索引；前次开发记录保留当时状态。

## 验证与遗留

沿用本轮已通过的后台 32 项测试、网页 4 项测试、类型检查与构建、模拟设备、编排器、纯视觉、投屏和平台配置检查。提交前复核后台测试、平台配置、Windows ZIP 校验与独立启动。

真机 Wi-Fi 连接、截图与投屏仍待验收；Mac 实机与完整 Linux 后台回归尚未执行。运行数据、令牌、模型密钥与本机压缩包不提交。

## 用户验收补充

用户随后在提交前确认：真机 Wi-Fi 连接、截图和投屏均已验收通过。Windows 真机待办关闭；仍保留 Mac 实机与完整 Linux 后台回归待办。
