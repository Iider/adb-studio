## 网页实际编排

- 从空白草稿添加循环、点击和滑动，点选点击位置、拖动滑动路线，再用下拉框连接。两轮各点击两次、滑动一次，记录核对为 **4 次点击、2 次滑动**。
- 在同一草稿添加轮次判断、等待应用条件、下一轮、退出与超时结束，配置正反样本；所属循环自动关联。第一轮提前退出，记录核对为 **2 次点击、1 次滑动**。
- 框选文字识别区域，不填页面依据时，目标出现、缺失分别到达符合、不符合出口；等待条件按相同规则满足或超时。填写页面依据后，依据不匹配则停在判断节点请求处理。
- 按键任务暂停后刷新网页，仍能继续同一条记录；重新打开已存草稿后无需重复保存工作流即可运行。
