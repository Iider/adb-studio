# 三个应用每日领取：实测记录

历史参考：关联旧任务已移除，不再作为操作说明。当前创建方式见[工作流说明](workflows.md)。

目标手机：飞牛 USB 连接的 iQOO（`3430131496001EB`）。只通过飞牛工作台运行签到动作；观察页面时可以用飞牛 ADB 截图。以下结论截至 2026-10-24，应用改版后需重新采样。

## 快手极速版

- 包名：`com.kuaishou.nebula`。
- 从首页点底部“去赚钱”进入任务中心。当天未签到时，实测自动弹出“连续签到”窗口，按钮先是“看视频30秒签到”。
- 工作台版本 1 已试跑：点击该按钮后，首页视频右侧出现约 30 秒倒计时，结束显示“已完成”。此时**尚未签到**。
- 再进入“去赚钱”，弹窗按钮变为“立即签到”。工作台版本 2 已试跑点击；弹窗从“已连签 2/14 天”变为“已连签 3/14 天”，显示“明日签到可领”。“我的收益”记录 2026-10-24“多天签到额外奖励 +4588 金币”。用户确认结果达标。
- 签到后退出并再次进入任务中心，未重现签到弹窗。未签到时关闭弹窗再进入是否会重新弹出，需下次可签到时验证。任务中心也可能先弹出其他活动窗口，不能把任意弹窗当签到入口。

## 抖音极速版

- 包名：`com.ss.android.ugc.aweme.lite`。首页左侧红包可进入“赚钱任务”。
- 用户要求做“天天领金币”和“预约领金币”，不做“7天签到必拿”。顶部“签到30天”挑战也不在本任务内。
- “天天领金币”：从任务页“去领取”进入钱包页，再点今日的“领取”。2026-10-24 工作台试跑使余额从 5258 增至 5268，按钮变为“今日已领”；用户确认达标。
- “预约领金币”：从任务页“去预约”进入预约页，再点中间“立即预约领取”。工作台试跑后显示“恭喜预约成功，记得明日来领奖励”；用户确认达标。次日可领取的画面与操作仍待采样。
- 同页右上“看广告赚钱”是另一个入口。工作台试跑先出现 518 金币“惊喜奖励”窗口，点“领取奖励”后进入广告直播间，观看并退出后页面显示“领取成功”；用户确认达标。退出时还会出现“再看一个视频额外获得 518 金币”的邀请。用户要求只要仍有可领奖励就继续看，直到页面明确显示没有可领的奖励；每轮需确认奖励和退出状态，不能只按固定次数循环。
- 任务页会滚动，先前试跑使用的固定坐标不能直接用于每天定时；需按页面内容重新定位并在领取后检查成功状态。

## 必应 Rewards

- 包名：`com.microsoft.bing`。底部第四个“应用”按钮进入应用页，点“Rewards”进入积分页。
- 积分页有“签入”卡片。2026-10-24 14:16，右侧显示 9 小时 43 分钟倒计时，当前不可再次领取，推算约在北京时间 24:00 刷新。
- 倒计时结束后，需采集可签到状态与工作台领取后的截图，再验证可领取分支。不能把页面右上角的搜索或兑换卡片当成签到。

## 仓库中的试跑文件

`workflows/daily-checkin.json` 与 `workflows/douyin-*.json` 共 10 份，是 iQOO 的分步试跑存档。`daily-checkin` 版本 2 只包含快手的立即签到步骤，名称中的“三个应用”表示目标范围，不表示三个应用已完成。

这些版本包含按当时页面采集的固定坐标；结束为“成功”只表示该段执行结束，领取结果仍需人工核图。它们不能直接用于荣耀，也不能直接设置每日定时。截图样本以原工作台返回的文件名引用，图片保存在原后台数据中，未随 Git 提交；换后台时须一并迁移样本，或重新采样。

其中 5 份使用本地文字识别，保留作历史参考；后续新版本使用纯视觉识别，不改写已保存的旧版本。重新使用前，核对目标手机、应用与画面，验证样本并真机试跑，再由用户确认。
