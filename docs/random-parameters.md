# 节点随机参数

参数来源支持固定值、随机值和已定义变量。选择随机值后，最小值、最大值分别选择固定数字或已有变量，可混用；变量使用本次运行输入，未覆盖时使用默认值。

每个随机字段可独立选择取值方式：

| 方式 | 取值规则 |
| --- | --- |
| 本次任务固定 | 第一次执行该节点时抽取，此任务之后再次进入该节点沿用同一数值 |
| 每次进入重抽（默认） | 每次进入节点重新抽取；同一次进入中的重复动作沿用本次参数 |

“本次任务”指一条运行记录。重新启动任务或重新单步执行会创建新记录，重新抽取。重抽可能恰好得到相同数值。

需要每次滑动重新随机间隔时，使用“循环 → 滑动 1 次 → 随机等待 → 进入下一轮”，随机等待选择“每次进入重抽”。滑动节点自身的间隔只用于该节点内部的多次动作；若一个节点滑动 1000 次，进入时抽到的间隔会在这 1000 次中沿用。

- 次数、轮数：区间内整数，包含两端；区间引用的变量必须为整数类型。
- 毫秒时长：区间内整数毫秒。
- 秒数、间隔：区间内随机时间，精度为 0.001 秒。
- 循环节点在开始整段循环时取值，轮数及轮间间隔在该循环内保持一致。推进下一轮不视为重新进入；已结束循环不可从外部重新进入。循环体内普通节点按自身方式取值。
- 结果在执行前保存并写入记录，说明首次抽取或沿用。暂停、断线、服务重启及停止后继续均保留已开始节点的结果；“本次任务固定”还会保留此前各节点的结果。
- 最小值不能大于最大值，区间两端必须符合原字段范围；两端相等且满足字段精度时始终得到该值。启动时先解析变量，再按最大值检查动作上限，实际进入节点时抽取。
- 草稿、克隆、保存与导出保留区间配置；单步测试同样会取随机值。

## 文件格式

仅用于原本支持运行变量的数字字段。例如：

```json
{"random":{"min":{"input":"变量编号"},"max":5,"mode":"run"}}
```

`min`、`max` 可为数字或变量引用；`mode` 为 `run`（本次任务固定）或 `visit`（每次进入重抽）。旧文件未写 `mode` 时按 `visit` 处理，兼容已有固定数字、变量引用及数字区间。

草稿、克隆和导入导出保留端点引用及方式。运行保存解析后的区间、方式和固定结果，固定结果不进入工作流文件，不与新任务共享。

变量区间与两种方式已通过用户验收；开发、部署及实测范围见[实施方案](random-parameters-v2-plan.md)。
