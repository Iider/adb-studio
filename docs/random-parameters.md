# 节点随机参数

参数来源支持固定值、随机值和已定义变量。来源下拉框缩窄；随机值右侧并排填写最小值、最大值。

- 次数、轮数：区间内整数，包含两端。
- 毫秒时长：区间内整数毫秒。
- 秒数、间隔：区间内随机时间，精度为 0.001 秒。
- 每次进入普通节点重新取值；同一次进入中的重复动作沿用本次参数。循环节点在进入整个循环时取值一次，轮数及轮间间隔在该循环内保持一致。
- 结果在执行前保存并写入记录。暂停、断线、服务重启后继续沿用本次结果，避免等待时间和剩余次数改变。
- 最小值不能大于最大值，区间两端必须符合原字段范围；两端相等且满足字段精度时始终得到该值。检查与动作上限按最大值计算。
- 草稿、克隆、保存与导出保留区间配置；单步测试同样会取随机值。

存储形式：`{"random":{"min":2,"max":5}}`，仅用于原本支持运行变量的数字字段，兼容已有固定数字和变量引用。
