# 节点编辑与单步测试

状态：开发及必要检查完成，已部署 Mac 本地工作台 17841，用户验收通过。

## 需求与交互

1. 点击、滑动的位置标注保存截图及手机屏幕信息。再次编辑优先使用上次截图并显示原坐标；只有首次无截图或点击“重新获取”才请求新画面。切换手机时分别恢复对应截图；截图不可用时说明原因，由用户重新获取。
2. 普通节点右键菜单提供“克隆”“删除”。克隆在旁边空位生成独立节点，复制截图、手机标注和全部参数，清空连线，支持撤销。开始标记是工作流入口，不生成第二个入口；其菜单说明不能克隆或删除。
3. 移除“从这一步开始执行”，使用“执行此步骤”。测试只执行选中节点，不跟随连线，也不修改工作流入口。使用节点引用变量的默认值；缺少默认值时弹窗填写，确认后执行。复用现有手机互斥、运行记录、暂停停止、输入校验和未确认动作保护。
4. 无任何连线且不是入口的节点视为孤儿节点。草稿检查忽略其未完成参数；保存保留这些节点，生成可运行流程时忽略它们。已有连线但未接入主流程的片段继续提示，避免误以为整段会执行。
5. 详情栏删除选择步骤、连接去向、方向移动及设置入口操作；用画布选择、连接与拖动完成这些操作。
6. 参数来源下拉框与数值输入同行，下拉在左；条件的判断方式与目标内容也同行。右栏适度增宽，窄窗口保持字段可用。

## 实现

- 位置截图保存到本机数据目录，以不可变编号引用；标注参数沿用 profiles／regions。复用当前取图接口和图片鉴权，图片不进入日志。刷新、克隆及草稿恢复保留引用。
- 前后端使用一致的孤儿节点定义；草稿保留全部内容，编译仅纳入参与连接及入口的节点。孤儿参数不影响设备适用范围或运行变量要求。
- 单步测试走独立接口，接收当前草稿及目标节点，不要求保存完整工作流。运行记录明确标识单步测试；后端保证一次节点执行后停止。
- 点击、滑动、按键、等待按节点参数执行；条件只判断并记录结果；循环只检查本节点的轮数／间隔，记录结果，不进入循环体；进入下一轮／退出循环记录该控制意图，不跳往其他节点。结束节点按结果结束。开始标记仅管理变量，不产生手机动作。
- 复用已有菜单、弹窗、下拉、撤销历史及运行参数表单，更新相关说明与模拟检查。

## 交付检查

- 截图：首次获取、原图再编辑、重新获取、离线原图编辑、刷新恢复、不同手机标注。
- 克隆：所有普通节点、全部参数与截图保留、无连线、旁边不重叠、撤销删除。
- 单步：实际动作只到本节点；默认值直接使用；缺值弹窗；取消不执行；变量校验；条件及循环控制不执行后续；同机互斥与未确认动作保护。
- 孤儿：空参数孤儿不影响检查／保存／运行，仍能单独编辑测试；连接后的节点恢复正常检查。
- 页面：详情栏精简、同行参数、右键键盘关闭、边缘位置、日夜与窄窗口。
- 执行必要的 Rust、网页与模拟设备检查；备份后更新本地工作台，真实手机效果由用户测试。
