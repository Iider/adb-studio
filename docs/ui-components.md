# 网页组件

## 工作台顶栏

左侧 Logo 栏与右侧顶栏统一高 52px；图标与文字作为整体水平居中，Logo 下方不加分隔线。Logo 图标为 28px，名称为 18px；窄屏沿用 52px 顶栏，主题按钮保留 40px 点击高度。编排器使用独立的 64px 顶栏。

## 模块间距

工作台页面四周、工具栏与卡片之间、主要卡片之间统一使用 `--workspace-gap: 19px`。滚动条占用外侧留白，不额外挤开卡片；设备右栏保留独立滚动。卡片内的表单与按钮间距沿用原设置。

## 滚动条

滚动条默认透明，滚动时显示，停止 1.5 秒后隐藏；嵌套区域分别计时。Chromium／WebKit 使用 4px 宽度，其他浏览器使用原生细滚动条。显隐保持占位与内容宽度不变。

主页、编排器、弹窗、下拉列表和文本输入区共用根布局的滚动监听。开发与验收约定见项目级 [前端规范](../.agents/skills/adb-studio-frontend/SKILL.md)。

## 下拉选择

组件：`web/src/lib/components/ui/dropdown/dropdown.svelte`。使用现有主题颜色，支持日间／夜间模式；弹层不受父容器裁切，靠近窗口边缘时调整位置。

```svelte
<script lang="ts">
  import Dropdown from "$lib/components/ui/dropdown/dropdown.svelte";
  let value = $state("one");
  const items = [{ value: "one", label: "第一项", description: "补充说明" }];
</script>

<Dropdown {items} bind:value label="选择项目" placeholder="请选择" />
```

- `items`：每项提供唯一的 `value`、`label`，可选 `description`、`disabled`；允许附带业务数据。
- `disabled`：禁用整个组件；没有选项且未提供置顶入口时自动禁用。
- `selection(item)`：自定义已选内容；`content(item)`：自定义列表项内容。
- `actions(item, close)`：列表项右侧的操作入口。按钮应提供可读的 `aria-label`，使用 `role="menuitem"`、`tabindex={-1}`；打开弹窗前调用 `close()`。此入口不会改变选中项。
- `leading(close)`：列表顶部的独立操作，约定与右侧入口相同；没有选项时仍可使用。设备下拉用它提供“添加局域网设备”。
- `onchange(value)`：选择条目后调用；置顶操作与右侧编辑入口不会触发。
- Enter／空格展开或确认，方向键移动焦点，Home／End 到达首尾，输入名称前缀定位；Esc 关闭并返回触发按钮，Tab 离开，点击外部关闭。

设备管理页的下拉列表显示名称、型号和连接状态。编辑图标复用“重命名手机”弹窗与现有保存接口，修改未选中的设备不会切换当前手机或结束投屏。

设备下拉框右侧依次为屏幕开关、唤醒、锁屏和截图，两个右栏页签共用这组操作；窄屏自动换行。屏幕关闭时按钮显示“点亮屏幕”。设备状态由后台持续更新。

## 设备右栏

`DeviceManager.svelte` 的 `detailTab` 支持 `parameters`、`task`，通过 `taskPanel(device)` 接收任务视图。页签只切换右栏内容，`LiveScreen` 不随页签重新创建。桌面右栏独立滚动；窄屏沿用上下排列。

任务设置与执行记录复用 `+page.svelte` 中的 `taskLaunch`、`runDetails`，与原任务页、记录页保持一致。设备页只显示带播放图标的“直接运行”，按当前启用版本启动，不显示版本选择；未启用的任务需先到自动化任务页试跑并启用。原任务页仍可选择版本与试跑。暂停和停止的记录共用继续按钮与恢复接口，按原快照保留进度继续。

设备页启动后保留当前页面和手机；优先展示该手机未结束的任务，没有时展示最近一次记录。运行参数仍固定在启动时，编辑只影响下一次启动。事件请求在切换设备或关闭任务右栏时取消。

“任务设置”使用原生 `details`：空闲默认展开，开始任务或打开运行中设备时默认折叠，点击标题或右侧箭头可切换。进度刷新保留手动展开状态；任务停止或完成后恢复展开。设备页正常执行时省略重复状态说明，暂停、停止和异常说明仍显示。

浏览器标题跟随当前手机：有未结束任务时为“手机名称 · 任务名称”，空闲时为“手机名称 · 空闲”；未选手机时为“手机自动化”。暂停、等待设备与恢复中的任务仍使用任务名称。

## 浮动通知

`web/src/lib/notifications.ts` 统一提供 `notify.success(message)`、`notify.error(message)`。布局中的 `ToastViewport` 在页面右上角显示，不占内容空间；新增提示向上移动 18px 并渐显，动画 320ms，完整停留 3 秒后用 160ms 淡出，也可点关闭。系统开启减少动画时直接显示和隐藏。

最多同时显示 3 条通知；相同类型、相同内容在显示期间合并。每条单独计时，关闭或离开页面时清理计时器。通知跟随当前模态弹窗或全屏容器显示，保持可读和可操作。

保存、截图、任务操作、局域网连接、投屏及识别检查的操作提示共用此入口。任务执行记录、识别结果和禁用按钮旁的条件说明持续保留。后台持续断连时，相同错误只提示一次，恢复连接后重置。

## 工作流编辑顶栏

`WorkflowEditor.svelte` 的顶栏固定单行、高 64px，包含返回、工作流名称、保存状态及常用操作。窄窗口缩短按钮文字，并将检查和保存版本入口收进“更多”，不换行、不挤高画布。

试跑手机与运行记录放在“试跑”弹出面板；草稿切换、新建、副本、删除及主题设置放在“更多”。保存失败、版本检查失败或浏览器恢复内容通过顶栏提示入口查看，并自动展开详情。面板使用原生 `popover`，浮于画布上方，支持点击外部或 Esc 关闭。窄屏的步骤面板切换固定在底部。

## 页面加载与缓存

主页通过网址参数保存当前位置：`tab` 指定栏目，`device` 与 `section` 指定设备及右侧面板，`workflow` 与 `version` 指定任务版本，`run` 指定执行记录。刷新后恢复对应页面；未知栏目回到设备页，无效版本使用该任务的最新版本。页面切换同步替换当前网址，不增加浏览器历史条目。

网页入口、`/_app/version.json` 和接口响应使用 `Cache-Control: no-store`，避免更新后从缓存读取引用旧脚本的页面。带内容指纹的 `/_app/immutable/` 资源保留浏览器缓存；缺失资源返回 404，不回退为 HTML。`/editor` 等前端页面回退到入口文件，返回 200。集成检查覆盖入口缓存规则与资源是否齐全；网页验收包含主页与编辑器往返。

编辑器重新打开草稿时按工作流编号恢复最新版本与最近的试跑，优先找回未结束任务；切换草稿清除上一份草稿的运行显示。版本比较忽略 JSON 字段顺序与画布位置，避免仅刷新后误报需要重存。试跑记录显示版本号，最近 30 条事件在面板内滚动。未标注的手机不可选为该版本的试跑目标。循环、点击与滑动设置显示保守的手机操作次数上限；连线不完整或循环结构无法确认时不显示确定次数。
