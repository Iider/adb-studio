# ADB 工作台 V2 方案

状态：第一阶段的设备页与公共外观已验收。日期：2026-10-19。

前置优化：[截图提速](screenshot-performance.md)已完成并获用户确认。

以 `pulse-adb-fusion-v2.html` 为界面参考，复用当前工作台后台，按三个阶段推进。原型中的模拟数据、执行结果和设置提示，需要接入真实功能后才能使用。

## 第一阶段 界面升级

- 本轮：公共侧栏、顶部栏、日间／夜间主题、设备卡片、搜索与详情。
- 后续：自动化任务、定时任务、执行记录、系统设置的内容布局逐页对齐；总览按真实状态接入。
- 总览突出：正在执行、等待手机、需要处理、下次定时。
- 手机页保留：重命名、常亮、唤醒、锁屏、截图、点击位置标注。
- 保留：版本试跑、定时执行、同机任务避让、断线等待与恢复、停止任务、截图记录、模型设置。
- 调整：放大文字，区分“已启用”和“执行中”，补齐窄屏导航。

验收：现有任务、定时和记录可继续使用；页面显示真实状态；常用操作容易找到、文字容易阅读。

### 本轮对照与验收

以原 Demo 的设备管理页做 1280 × 720 同尺寸截图对照。侧栏 244 px、顶部栏 70 px；内容左边距 38 px，设备卡片三列、间距 18 px，首张卡片位置为 (282, 255)，宽 308 px、高约 378 px。深浅主题沿用 Demo 的配色。

内容使用真实设备与状态；电量区域显示现有“保持常亮”状态，“添加设备”改为“刷新设备”。导航仅列出已接入的五项功能。唤醒、锁屏、截图、标注等操作位于设备详情；“屏幕预览”可单独查看截图。窄屏使用底部导航。

- 样式：对照设备页的字号、配色、间距、圆角与卡片尺寸。
- 操作：搜索设备，进入详情，截图，打开并取消重命名／位置标注，跳转任务与记录。
- 状态：离线设备禁用手机操作，常亮状态与原有设置一致。
- 显示：切换主题后刷新，检查主题保留；窄屏检查底部导航与屏幕预览。

## 第二阶段 流程图展示

- 展示现有工作流步骤、分支和结束位置。
- 突出当前执行步骤，显示失败原因及相关截图。
- 进入流程图时收起主侧栏；属性、日志面板可以折叠。
- 本阶段先提供查看功能，流程仍由 Agent 维护。

验收：能看清完整流程，找到当前步骤和失败位置；显示内容与实际执行一致。

## 第三阶段 新能力

按需要逐项选择：可视化编辑、找图点击、通用循环、通知、实时投屏。

- 每次只实现一项，优先复用现有方案。
- 可视化编辑接入现有版本、验证和试跑机制，流程由后台保存。
- 找图适配真实截图尺寸和折叠屏；通知、投屏接入真实服务。
- 接入投屏后复用最新画面，保留原图回退，详见 [Aya 实时控制参考](aya-reference.md#截图提速建议)。

验收：所选功能完成真实操作；失败、停止和断线情况有明确反馈。

## 推进方式

每阶段拆成可单独测试的小功能。完成一项后请用户测试，确认达标后再做对应的本地 Git 提交。
