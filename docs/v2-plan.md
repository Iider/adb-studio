# ADB 工作台 V2 方案

状态：设备页、公共外观、任务列表与启动入口、定时任务页、人工接管与继续均已验收。日期：2026-10-20。

前置优化：[截图提速](screenshot-performance.md)已完成并获用户确认。

以 `pulse-adb-fusion-v2.html` 为界面参考，复用当前工作台后台，按三个阶段推进。原型中的模拟数据、执行结果和设置提示，需要接入真实功能后才能使用。

- 已验收：公共侧栏、顶部栏、日间／夜间主题、设备卡片、搜索与详情。

- 执行记录：复用现有“左侧列表、右侧详情”，保留默认显示详情；按需要借用 Demo 的筛选与耗时信息。
- 已验收：定时任务卡片、搜索筛选、新建／修改表单与删除确认。
- 后续：系统设置的内容布局对齐；总览按真实状态接入。
- 总览突出：正在执行、等待手机、需要处理、下次定时。
- 手机页保留：重命名、常亮、唤醒、锁屏、截图、点击位置标注。
- 保留：版本试跑、定时执行、同机任务避让、断线等待与恢复、停止任务、截图记录、模型设置。
- 调整：放大文字，区分“已启用”和“执行中”，补齐窄屏导航。

验收：现有任务、定时和记录可继续使用；页面显示真实状态；常用操作容易找到、文字容易阅读。

### 设备页（已验收）

以原 Demo 的设备管理页做 1280 × 720 同尺寸截图对照。侧栏 244 px、顶部栏 70 px；内容左边距 38 px，设备卡片三列、间距 18 px，首张卡片位置为 (282, 255)，宽 308 px、高约 378 px。深浅主题沿用 Demo 的配色。

内容使用真实设备与状态；电量区域显示现有“保持常亮”状态，“添加设备”改为“刷新设备”。导航仅列出已接入的五项功能。唤醒、锁屏、截图、标注等操作位于设备详情；手机屏幕直接与设备信息并列显示，不再设置独立预览页或设备标签栏。窄屏使用底部导航。

- 样式：对照设备页的字号、配色、间距、圆角与卡片尺寸。
- 操作：搜索设备，进入详情，截图，打开并取消重命名／位置标注，跳转任务与记录。
- 状态：离线设备禁用手机操作，常亮状态与原有设置一致。
- 显示：切换主题后刷新，检查主题保留；窄屏检查底部导航与手机屏幕。

### 任务列表与启动入口（已验收）

以原 Demo 的任务页做 1280 × 720 同尺寸截图对照，沿用双列卡片、图标区、步骤标签、信息行和底部按钮；顶部加入搜索与状态筛选，窄屏使用单列。

- 按任务合并历史版本；卡片优先展示已启用版本。“运行”打开已启用版本，“详情”打开最新版本；新版待试跑时显示单独入口，也可通过“待试跑”筛选找到。
- “已启用”表示有可运行版本；“进行中”包含执行、等待手机、恢复及人工暂停。显示真实状态，未结束的任务可分别停止。
- 记录次数仅统计当前保留的执行记录，包含试跑；清理后的历史不作累计数展示。
- 进入详情后选择手机、版本及参数；保留试跑、直接运行、启用／回退、位置标注和步骤查看。离线、锁屏、同机占用及缺少点击位置时提示原因；非法参数由表单拦截。
- 原型的演示开关改为真实版本状态；“编辑”改为“详情”，任务制作继续由 Agent 维护。

验收：搜索与筛选、返回列表时保留筛选；运行入口版本正确；参数校验及离线提示清楚；深浅主题和窄屏正常。启动与停止请求使用模拟设备核对，不改变真机页面。

### 执行记录（布局复用）

保留“左侧列表、右侧详情”，默认显示最新记录；左侧切换后直接查看进度与结果。复用真实步骤、判断依据、关键画面及停止／导出／清理操作。

可按需要补充状态筛选、按任务或手机搜索、开始／结束时间与耗时，沿用已接入的配色与卡片样式；小幅优化单独验收。

### 定时任务（已验收）

原 Demo 没有独立的定时任务页，沿用其任务页的双列卡片、图标、配色、圆角及按钮样式；窄屏单列。卡片按已开启优先、下次时间排序，显示手机、任务、运行参数、执行规则、下次执行与最近触发结果。“已开始”只表示触发，不代表任务完成。

- 搜索定时名称、任务或手机，筛选全部／已开启／未开启。
- “新建定时”与“修改”使用独立表单；修改带回原参数，新建恢复默认值，取消不保存。保存失败保留输入并显示原因。
- 保留单次、每天、每周、间隔四种规则及点击／滑动参数；全部使用上海时间。单次时间必须在未来，每周至少选一天。手机按任务适用范围选择；离线手机可以保存未来定时。
- 区分已开启、已暂停、单次已到期；到期单次需修改时间后再次开启。删除需要确认，已开始的任务和记录保留。
- 后台定时规则保持现状：保存／修改会重新计算下次时间并清空最近触发结果；固定间隔从保存时间起重新计时。

验收：搜索筛选，四类时间规则，修改与取消，暂停／开启，删除确认，深浅主题与窄屏。创建、修改、启停及删除请求使用隔离模拟服务核对，不创建真机定时。

### 人工接管与继续（已验收）

执行记录保留左右布局，加入“人工接管”与“继续任务”。工作台统一处理暂停，不增加工作流节点或修改已有版本。

- 请求后显示“正在暂停”；在途命令结束、进度保存后显示“已暂停”，此时才可手动操作。
- 暂停继续占用手机，定时任务避让；后台重启保持暂停，可继续或停止。继续前检查连接、亮屏、解锁与原应用，应用内的具体页面由用户确认。
- ADB 超时或触控拒绝转为暂停；不自动重试权限错误。未确认的循环滑动不补发，保留尝试次数并明确标注；未确认且无法验证的点击或单次滑动拒绝继续。
- 报错显示简短原因，技术详情默认折叠；旧的已结束记录保留。

验收：短任务接管／继续／停止，接管期间手动操作；异常暂停、重启、定时避让、未确认动作使用隔离模拟设备检查。正式后台与网页已更新，用户已验收通过。
