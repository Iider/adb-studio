# ADB 工作台 V2 方案

状态：待实施。日期：2026-10-18。

以 `pulse-adb-fusion-v2.html` 为界面参考，复用当前工作台后台，按三个阶段推进。原型中的模拟数据、执行结果和设置提示，需要接入真实功能后才能使用。

## 第一阶段 界面升级

- 页面：总览、手机、任务、定时、记录、设置。
- 总览突出：正在执行、等待手机、需要处理、下次定时。
- 手机页保留：重命名、常亮、唤醒、锁屏、截图、点击位置标注。
- 保留：版本试跑、定时执行、同机任务避让、断线等待与恢复、停止任务、截图记录、模型设置。
- 调整：放大文字，区分“已启用”和“执行中”，补齐窄屏导航。

验收：现有任务、定时和记录可继续使用；页面显示真实状态；常用操作容易找到、文字容易阅读。

## 第二阶段 流程图展示

- 展示现有工作流步骤、分支和结束位置。
- 突出当前执行步骤，显示失败原因及相关截图。
- 进入流程图时收起主侧栏；属性、日志面板可以折叠。
- 本阶段先提供查看功能，流程仍由 Agent 维护。

验收：能看清完整流程，找到当前步骤和失败位置；显示内容与实际执行一致。

## 第三阶段 新能力

按需要逐项选择：可视化编辑、找图点击、通用循环、通知、实时投屏。

- 每次只实现一项，优先复用现有方案。
- 可视化编辑接入现有版本、验证和试跑机制，流程由后台保存。
- 找图适配真实截图尺寸和折叠屏；通知、投屏接入真实服务。
- 截图提速先优化现有路径；接入投屏后复用最新画面，保留原图回退，详见 [Aya 实时控制参考](aya-reference.md#截图提速建议)。

验收：所选功能完成真实操作；失败、停止和断线情况有明确反馈。

## 推进方式

每阶段拆成可单独测试的小功能。完成一项后请用户测试，确认达标后再做对应的本地 Git 提交。
