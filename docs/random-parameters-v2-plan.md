# 随机参数：变量区间与取值方式

状态：开发及模拟验证完成，已更新 Mac 本地工作台 17841，用户验收通过。沿用现有随机参数、运行变量、单步测试及运行记录，不新增变量系统。

## 使用规则

随机值的最小值、最大值分别选择“固定值”或已有变量，可混用。变量使用本次运行输入；未覆盖时使用默认值。次数的区间变量必须是整数变量，单位及范围由节点字段决定。

每个随机字段独立选择取值方式：

| 方式 | 行为 | 示例 |
| --- | --- | --- |
| 本次任务固定 | 第一次执行该节点时抽取，此任务之后再进入该节点沿用同一数值 | 点击次数首次取到 3，后续每轮仍为 3 |
| 每次进入重抽 | 每次重新进入节点抽取一次；同一次进入中的重复动作沿用该次数值 | 第一次进入点击 3 次，下一轮重新取次数 |

重抽可能恰好得到相同数值，不保证相邻两次不同。暂停、断线、服务重启及停止后继续均不重抽已开始的这次节点参数；“本次任务固定”的缓存保留在该运行中。新启动任务或重新单步执行创建新运行，重新取值。

循环节点的“进入”指开始一整段循环：轮数和轮间间隔在这段循环内固定，回到循环节点推进下一轮不视为重新进入。已结束循环不可从外部重新进入，沿用现有执行器限制，本轮不扩展循环重入能力。循环体内普通节点按自身设置取值。

## 编辑器

- 随机字段下方显示最小值、最大值，各自复用现有下拉选择固定数值／变量；变量显示可读名称或别名。
- 同一随机字段提供“取值方式”下拉，默认“每次进入重抽”，与旧普通节点行为一致。
- 缺失变量、无默认值、类型不匹配、越界及最小值大于最大值明确提示；不默默改值。保存、运行及单步使用同一校验规则。
- 节点摘要显示区间，变量显示名称，不显示对象文本。运行记录说明首次抽取或沿用，以及对应方式。

## 存储与兼容

沿用 `random` 对象，区间端点支持数字或 `{ "input": "变量编号" }`；新增可选 `mode`：`visit` 表示每次进入重抽，`run` 表示本次任务固定。例如：

```json
{"random":{"min":{"input":"变量编号"},"max":5,"mode":"run"}}
```

旧配置没有 `mode` 时按 `visit` 处理。草稿校验允许未填写端点，完整保存／运行拒绝缺项。启动时按本次变量值解析区间，再按最大值核对动作上限；实际进入节点时按所选方式抽取或沿用。运行中保存数值区间、取值方式与任务固定缓存，新增缓存字段缺省为空，旧运行继续沿用原取值与恢复保护。

变量收集必须覆盖区间两端，避免保存、单步表单、运行输入、删除检查和导入导出遗漏引用。克隆复制配置，运行缓存不进入工作流文件，也不共享给其他节点或任务。
