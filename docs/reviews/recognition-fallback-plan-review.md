## 核对依据与范围

- `src/api.rs::set_model`、设置表单：字段仍是环境变量名称，当前不支持直接保存 API Key。
- `src/recognition.rs`：Frame／Word、区域过滤、金币提取、两种模型请求、512 token 输出预算、请求超时和暂停取消。
- `src/canvas.rs::evaluate`、`observe` 与等待条件：页面依据先于区域匹配，读字错误转为未知，等待时长在观察后结算。
- `src/engine.rs::start` 与旧读字调用：启动时限制本地工具，文字结果用于定位、分支、操作前后检查和金币识别。
- 修订后的方案仍复用现有执行器和页面，不新增工作流识别模式、模板转换或自动换模型；格式与来源字段仅用于配置和执行状态。

已复核文档的状态说明、代码路径与相对链接。没有修改业务代码、正式配置或密钥，也没有发送真实模型请求。保存失败复现沿用前一轮隔离证据，本轮不将文档审查等同于功能测试。
