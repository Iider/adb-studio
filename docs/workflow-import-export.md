# 工作流导入与导出

文件导出与副本导入已实现。当前只支持画布编辑器工作流和未完成的草稿；旧任务、裸本体和缺少草稿的文件不支持。

任务页右上角提供新建和导入；任务卡片“更多”导出已保存本体与关联草稿；编辑器“更多”导出当前草稿。导入后可继续编辑，不自动运行或创建定时。

本体和草稿分别保留；草稿不同或尚未完成时提示差异，不能重新编译草稿来覆盖文件中的本体。新副本生成新 UUID，内部连线、标注和画布布局保留；手机编号保留，换手机需重新标注。

变量定义、默认值和节点引用随本体／草稿分别保留；含变量文件使用第 2 版格式，新程序兼容第 1 版。临时运行值不随工作流导出。

接口、格式、体积限制与重试规则见[工作流说明](workflows.md#工作流文件导出)。执行记录导出文件不用于工作流迁移。

覆盖导入待开发：须明确选择目标并确认覆盖，保留运行快照，处理草稿冲突与关联定时；不自动恢复旧任务。批量文件、ZIP、云同步和跨格式转换不在当前范围。
