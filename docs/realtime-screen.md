# 实时投屏

进入“设备管理”即可查看当前手机，顶部下拉可切换，列表中的编辑图标可修改对应手机名称，编辑不会切换设备。切换手机后原投屏与操作结束。在“手机屏幕”标题旁点击“开启投屏”。首次投屏时手机需已连接、亮屏；需要密码时在手机上解锁。通过工作台关闭实体屏幕后，可在保持解锁的情况下重新投屏。连接成功后自动申请操作权，成功后显示“操作中”；型号、手机编号、投屏尺寸与操作模式统一在右侧“设备信息”查看。

- 投屏连上后自动进入操作模式，正在执行的任务继续运行；停止投屏不改变任务状态。支持单指点按、按住拖动、四向滑动，以及返回／主页／最近任务。操作权申请失败时可点击“重试操作”。键盘文字输入、剪贴板、声音和录像尚未接入。
- 同一台手机只允许一个工作台页面投屏；另一页面会提示先关闭原投屏。不同手机可以分别观看。
- 切换浏览器页签或窗口时，保留投屏连接与手动操作模式，并取消尚未松开的触点；返回后继续观看或操作。点击“停止投屏”、离开设备页、切换手机、关闭网页或退出服务时，释放连接；断线后不自动重启投屏或任务。
- 折叠屏画面使用投屏卡片宽度；返回、主页、最近任务和全屏按钮位于画面顶部，四个无文字的滑动按钮位于“手机屏幕”标题栏右侧。全屏时滑动按钮显示在画面下方。按 Esc 或再次点击全屏按钮返回。
- 连接中可以取消；断线后清除画面并提示重新投屏，避免将旧画面误认作实时状态。投屏和控制错误统一以右上角浮动通知显示，停留 3 秒后消失；断线状态和“重试操作”入口持续保留。
- 默认 H.264，最长边 1280 像素，最高 30 帧／秒，码率 4 Mbps；实际流畅度取决于手机、连接和浏览器。静止画面可能不持续产生新帧。
- 旋转后跟随视频更新尺寸并重新申请操作权。首版使用 Android 主显示屏（display 0）；折叠屏切换需另行真机验证。
- 截图入口位于设备下拉框右侧，使用现有 ADB 原图截图，用于小字识别及位置标注。当前没有将网页视频画面接入后台识别或截图接口。

## 操作手机

右上角“设备参数 / 任务详情”只切换右栏，手机画面与投屏连接保留。“任务详情”可选择自动化任务与运行参数，默认使用已启用版本，不显示版本选择；没有已启用版本时，先到自动化任务页试跑并启用。点击绿色“直接运行”在当前页面启动，任务设置随即折叠；点击标题或右侧箭头可再次展开，进度刷新保留手动选择。空闲时默认展开。可查看步骤、次数、判断记录和关键画面，支持暂停、继续、停止与导出。已暂停、已停止的任务都可保留原参数和进度继续；同机另有任务或动作结果无法确认时拒绝继续。没有进行中任务时展示最近一次记录；修改的参数用于下一次启动。定点点击的标注保存后也返回此右栏。

1. 点击“开启投屏”，连接成功后自动进入操作模式，任务继续运行；申请操作失败时保留画面并提示原因。
2. 在画面中点按或按住拖动。返回／主页／最近任务可直接点击；上下左右滑动有独立按钮，画面获得键盘焦点后也可使用方向键。
3. 完成后点击标题旁的“停止投屏”。任务保持原来的运行或暂停状态。

开启操作时重新核验手机连接与解锁状态；普通息屏仍需先唤醒，通过工作台关闭的实体屏幕可保持关闭并继续操作。手动输入与任务动作可同时发生；切换应用或改变页面时，任务原有的检查仍可能暂停或停止任务。需要独占手机时，先到执行记录点“人工接管”；手动暂停的任务需主动点“继续任务”，投屏不会自动恢复。

设备下拉框右侧依次提供屏幕开关、唤醒、锁屏和截图。屏幕开关按钮在“关闭手机屏幕”和“点亮屏幕”之间切换；后台转发指令成功后更新按钮，等待期间不可重复点击。复用 Aya 相同的 scrcpy 屏幕电源指令。手机在线即可点击：未投屏时自动连接，取得操作权后发送息屏指令，任务继续运行。连接或权限失败时保留提示，不发送息屏指令。关闭的是实体屏幕，投屏与触控继续。关闭状态按手机保存；停止投屏、刷新网页、切换页面或手机、断线及后台重启均不主动点亮。开启“保持常亮”时，设备检查也会尊重此状态。点击“点亮屏幕”或使用“唤醒”“锁屏”后清除记录。手机断连或通道异常时仍可用实体电源键恢复；若手机自行锁定，需解锁后再投屏。此功能不同于“锁屏”，不修改自动锁屏或常亮设置。Mac、Linux 共用同一通道。

手动操作期间，这台手机可以启动新任务、定时任务或继续已暂停的任务；同一手机仍只允许一个任务运行，已暂停的任务继续占用手机。独立的锁屏与唤醒接口仍需先停止投屏，避免与投屏屏幕开关冲突。切换浏览器页签或窗口不结束操作模式；离开设备页或关闭网页会停止投屏。拖动离开画面时仍接收松手，指针取消、旋转、失去窗口焦点和断线时尝试取消触点。

画面留白不会触发手机操作；鼠标移入投屏画面仍显示普通箭头。坐标使用视频实际尺寸，适配缩放与全屏。导航键只允许返回、主页、最近任务，按下和松开发送成对消息。手机拒绝触控时结束操作模式并提示检查调试权限、重新投屏；不会自动重试动作。

## 浏览器

页签标题随所选手机更新：执行或暂停中显示“手机名称 · 任务名称”，没有未结束任务时显示“手机名称 · 空闲”。

需要支持 WebCodecs H.264 解码的现代浏览器，建议使用新版 Chrome／Edge。Mac 本机使用 `http://127.0.0.1:17841` 或 `http://localhost:17841`。局域网普通 HTTP 地址通常无法使用视频解码；其他设备访问需安全的 HTTPS 地址。

## 安装

下列命令用于 Mac 源码安装；Linux／Docker 与原生发行包见 [跨平台部署](deployment.md)。

在项目目录运行：

```sh
python3 scripts/setup-mirror.py
cargo build
cd web
npm ci
npm run build
cd ..
python3 scripts/install-service.py install
```

下载脚本从 scrcpy 官方发布获取固定的 3.1 服务端，验证 SHA-256 后保存至 `data/bin/`。安装脚本复制到正式服务目录。首次开启投屏会将服务端推送至已核验的手机临时目录，关闭后尝试删除本次文件；断线时手机端文件可能残留，可在下次连通后手动清理 `adb-studio-*.jar`。

## 连接与资源

Rust 后台沿用现有手机编号核验，固定本次 ADB transport；通过独立名称的 ADB reverse 通道接收视频，经已鉴权的同源 WebSocket 转发给 Svelte。通道与会话名称独立于 Aya，不会关闭其他软件的投屏。手机端开启视频与控制通道，设置 `audio=false`、`power_on=false`、`clipboard_autosync=false`、`cleanup=false`；退出时由工作台清理本次 ADB 通道与临时文件，避免 scrcpy 自动点亮实体屏幕。首帧显示后网页自动申请操作权；后台核验手机解锁状态，取得操作权之前不发送手机输入。

网页使用 `@yume-chan/scrcpy` 解析协议，使用 `@yume-chan/scrcpy-decoder-webcodecs` 解码并显示到画布，触控与导航消息直接复用协议库序列化。后台校验单指顺序、坐标范围及导航键白名单，并限制操作速率。操作模式只限制独立的锁屏与唤醒接口，不阻止任务启动或继续；同机任务互斥与恢复检查由执行引擎保留。连接关闭先取消触点，再关闭手机服务和释放占用。转发与解码队列有上限，处理过慢时结束连接并提示重开；不会无限积压画面。手机上的受保护内容可能显示黑屏。

## 检查与验收

```sh
cargo test
python3 scripts/check-mirror.py
node --experimental-strip-types scripts/check-touch.mjs
python3 scripts/check-integration.py
cd web
npm run check
npm run build
```

模拟检查涵盖访问限制、手机核验、原样转发、重复会话、未取得操作权时拒绝触控、点按拖动协议、导航键配对、操作中启动与继续任务、运行中开启操作、结束及断开操作后任务继续、人工暂停保留、同机任务互斥、权限拒绝、越界拦截、断线取消触点、息屏后结束与重开、定时刷新不唤醒、启动取消、息屏提示与服务退出清理；不操作真机。

用户验收：开启后观察手机正在变化的页面；检查画面连续性、延迟、旋转、停止后重开、切换浏览器页签后保留画面与操作模式、离开设备页后停止投屏、断线提示。分别核对 USB／无线、不同手机和常用浏览器。运行任务后开启投屏，应自动进入操作模式且任务继续；停止投屏后，任务仍继续。操作模式下可启动任务、继续已暂停的任务；主动暂停后，开关投屏均不自动恢复任务。基础控制需验收点按、拖动、四向滑动、三键、全屏以及暂停接管后的继续流程。

实时投屏与基础操作已验收；投屏操作与任务并行待用户真机验收。
