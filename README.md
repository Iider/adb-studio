# ADB 工作台

在 Mac 上管理手机、运行 Agent 制作的工作流、设置定时。

打开 [本机工作台](http://127.0.0.1:17841)。

## 使用

1. **设备管理**：搜索手机，进入“查看设备详情”；重命名、常亮、唤醒、锁屏、截图及点击位置标注都在详情内。
2. **自动化任务**：搜索或筛选任务，点“运行”／“试跑”进入详情，选择手机与参数。试跑通过后自动启用；“详情”可查看最新版本及步骤。
3. **定时任务**：搜索名称、任务或手机，筛选开启状态；卡片显示规则、下次执行和最近触发结果。点“新建定时”或“修改”，设置单次、每天、每周或间隔执行；支持暂停、开启及确认删除。
4. **执行记录**：查看进度、关键画面和判断依据；停止任务；导出或清理记录。

顶部可切换日间／夜间模式，浏览器会记住选择。窄屏使用底部导航。V2 范围与验收见 [升级方案](docs/v2-plan.md)。

任务卡片区分“已启用”和“进行中”。“运行”使用已启用版本；新版可单独试跑。记录次数为当前保留记录，包含试跑。进行中的任务可在卡片内停止。

记录页默认显示最新一条详情。详情中可清理单条，顶部可清理已结束的记录；清理前会确认。执行中、等待手机和恢复中的任务会保留。

USB 截图优先由电脑生成 PNG；不支持时自动回退手机截图。速度随手机和页面变化，实测结果与验收步骤见 [截图提速](docs/screenshot-performance.md)。

工作流由 Agent 修改，网页只读。正在运行的任务固定使用启动时的版本。

同一手机一次执行一个任务。定时滑动保持当前应用，应用改变时停止，请在目标页面重新开始。新任务遇到忙碌或离线会跳过；执行途中掉线会一直等待。恢复连接或后台重启后重新观察，未确认结果的点击不会直接重放。等待中的任务也可停止。

汽水音乐当前规则适配 iQOO 的 21.1.0 版本；版本改变会停止并提示重新适配。任务入口是“连续刷视频赚金币”的文字区域。识别先使用本机规则与文字，疑难画面调用已配置的豆包；无法确认时标记“需要处理”。

## 启动与自启

开发环境需要 Rust、Node.js 22.19+、Mac 自带 Swift；ADB 默认使用上一层目录的 `platform-tools/adb`。

```sh
cd web
npm ci
npm run build
cd ..
cargo build
mkdir -p data/bin
swiftc -O scripts/ocr.swift -o data/bin/ocr
python3 scripts/install-service.py install
```

查看后台：`python3 scripts/install-service.py status`。

关闭自启和后台：`python3 scripts/install-service.py remove`。

手动运行：`cargo run`。修改代码后，重新构建并安装服务。

后台不会更改 Mac 防休眠设置。手机常亮开关默认关闭；开启时保存原设置，关闭后恢复，离线时延后处理。常亮建议接电；密码锁屏需要本人解锁。无线重连使用已登记手机的已配对服务。

## 数据与模型

- 后台运行文件与数据：`~/Library/Application Support/ADB Studio/`；源码保留在本项目。
- 数据库、令牌、关键截图：后台目录的 `data/`；服务日志：`~/Library/Logs/ADB Studio/`。
- 手动开发运行的数据在本项目 `data/`，不进入 Git。命令工具通过 `data/service-root` 查找后台数据。
- 令牌文件仅当前用户可读。
- 手动清理从列表移除记录，本机归档、判断记录和截图仍保留。
- 未手动清理的记录和关键截图：保留 30 天；正在执行或等待的任务不会自动清理。
- 安装自启时，已有 `MODEL_KEY` 复制到后台目录 `.env`，仅当前用户可读；重新安装不会覆盖已有密钥。
- 更换后台密钥时编辑后台目录 `.env`；手动开发可使用环境变量、本项目或上一层 `.env`。
- 默认模型：`doubao-seed-2-1-lite-260915`，Responses 接口。
- 每次运行最多 10 次模型调用；同一次疑难识别最多 2 次。工作流可以声明其他上限，最高 100 次。
- 登录服务监听 `0.0.0.0:17841`，局域网可通过 Mac 的 IP 访问；网页和 Agent 接口仍验证访问凭据并检查同源请求。开发启动默认 `127.0.0.1`，可通过 `ADB_STUDIO_HOST` 修改监听地址。

Agent 使用 [工作流说明](docs/workflows.md) 与 [使用技能](.agents/skills/adb-studio/SKILL.md)。

## 检查

```sh
cargo test
python3 scripts/check-integration.py
cd web
npm run check
npm run build
```

集成检查使用临时数据库和模拟 ADB，不操作真机。它使用端口 17842；正式工作台使用 17841。

参考项目与组件来源见 [来源声明](THIRD_PARTY_NOTICES.md)。

进入设备详情后点击“标注点击位置”：在截图弹窗点选目标，确认保存，然后在“定点点击”设置次数与间隔。标注和运行互相独立，点击任务不识别页面。各手机分别保存位置；换屏或旋转后重新标注。
