# ADB 工作台

在 macOS／Linux／Windows 上管理手机、运行 Agent 制作的工作流、设置定时。

打开 [本机工作台](http://127.0.0.1:17841)。

## 使用

1. **设备管理**：顶部下拉切换手机，列表首项为“添加局域网设备”，每台手机旁的编辑图标可改名。下拉框右侧依次提供屏幕开关、唤醒、锁屏和截图。手机画面固定在左侧，右上角“设备参数 / 任务详情”只切换右栏：前者提供设备信息与常亮设置，后者支持选择任务、设置参数、查看当前任务或最近一次的执行记录，以及暂停、继续和停止。修改参数用于下一次启动，正在执行的任务保留原参数。切换右栏不关闭投屏；切换手机会停止原投屏与操作。
2. **自动化任务**：搜索或筛选任务，点“运行”进入详情，选择手机与参数。保存后即可运行；“详情”可查看当前内容及步骤。“更多 → 删除任务”会同时删除草稿、定时、全部执行记录、判断结果与运行截图，无法恢复。
3. **定时任务**：搜索名称、任务或手机，筛选开启状态；卡片显示规则、下次执行和最近触发结果。点“新建定时”或“修改”，设置单次、每天、每周或间隔执行；支持暂停、开启及确认删除。
4. **执行记录**：查看进度、关键画面和判断依据；人工接管、继续或停止任务；导出或清理记录。长报错默认显示简短说明，可展开“技术详情”。

首次添加局域网设备时，先配对，再返回手机“无线调试”主页，按当前显示的 IP 和连接端口连接。连接端口与配对端口不同，配对后也可能变化；扫描不到手机时可手动填写连接地址。

侧栏底部可切换日间／夜间模式，浏览器会记住选择。操作通知在右上角浮动显示，停留 3 秒后自动消失。窄屏使用底部导航。V2 范围与验收见 [升级方案](docs/v2-plan.md)。

任务卡片区分“已保存”和“进行中”。每项任务只保存一份内容，保存直接覆盖；“运行”使用当前保存的内容。记录次数为当前保留记录。进行中的任务可在卡片内停止。

记录页默认显示最新一条详情。详情中可清理单条，顶部可清理已结束的记录；清理前会确认。执行中、等待手机、恢复中和已暂停的任务会保留。

USB 截图优先由电脑生成 PNG；不支持时自动回退手机截图。速度随手机和页面变化，实测结果与验收步骤见 [截图提速](docs/screenshot-performance.md)。

设备管理页“手机屏幕”标题旁可开启或停止实时投屏；连接成功后自动进入操作模式，支持点按、拖动、四向滑动和返回／主页／最近任务，任务继续运行。停止投屏不改变任务的运行或暂停状态。折叠屏画面优先占用卡片宽度，导航键和全屏键位于画面顶部。切换浏览器页签或窗口保留投屏与操作模式，并取消尚未松开的触点；离开设备页后停止投屏。顶部操作区提供实体屏幕开关，未投屏时自动连接；息屏后可继续投屏操作与运行任务。原图截图独立保留。安装、浏览器要求与验收见 [实时投屏](docs/realtime-screen.md)。

同一手机的投屏可直接切换到当前页：点“开启投屏”会结束旧页连接；刷新正在投屏的页面会自动恢复。主动停止或被其他页面接管后，刷新保持停止；新页签需手动开启。投屏恢复不会自动继续已暂停的任务。

网页可通过“自动化任务 → 新建工作流”添加步骤、连线、按手机截图标注位置，并保存运行。新建始终打开独立的空白画布；继续修改已有任务请用卡片“编辑”。支持重复动作、组合循环、条件判断与等待，以及退出循环和进入下一轮。保存后直接运行，无需试跑或启用；正在运行的任务继续按启动时的步骤执行。开发进度与验收见 [人工编排工作流开发方案](docs/visual-workflow-editor.md)。

工作流文件[导入导出方案](docs/workflow-import-export.md)分单元开发：导出已验收并部署；导入仍待开发。任务卡片与编排器可分别导出任务、当前草稿，保留画布布局与引用的图片；操作与接口见[文件导出](docs/workflows.md#工作流文件导出)。

同一手机一次执行一个任务。定时滑动保持当前应用，应用改变时停止，请在目标页面重新开始。新任务遇到忙碌或离线会跳过；执行途中掉线会一直等待。恢复连接或后台重启后重新观察，未确认结果的点击不会直接重放。等待中的任务也可停止。

需要暂停任务、独占手机时，在执行记录点“人工接管”，等待显示“已暂停”后再操作；正在执行的命令会先结束。完成后回到原应用的目标页面，点“继续任务”。后台会检查连接、亮屏、解锁和原应用；同一应用内的具体页面由你确认。暂停会保留进度并继续占用手机，定时任务会避让；后台重启、手机重新连接都不会自动解除人工暂停。

ADB 超时或手机拒绝任务触控时，任务也会暂停，处理问题后再继续。已停止的任务也可点“继续任务”，保留原记录、步骤、参数与进度；同一手机不能同时另有任务。未确认的循环滑动保留尝试次数，不补发；未确认且无法验证结果的点击或单次滑动拒绝继续，需核对页面后重新开始。已完成或需要处理的记录不继续。投屏手动操作、外部 ADB 和直接触屏可能改变任务页面；需要独占手机时，请先主动接管。

汽水音乐当前规则适配 iQOO 的 21.1.0 版本；版本改变会停止并提示重新适配。任务入口是“连续刷视频赚金币”的文字区域。识别先使用本机规则与文字，疑难画面调用已配置的豆包；无法确认时标记“需要处理”。

## 启动与自启

Windows 安装与连接手机见 [Windows 部署](docs/deployment.md#windows-部署)。已安装时打开 [本机工作台](http://127.0.0.1:17841)，后台登录自启。

已验证的飞牛 Linux x86_64 部署包与用法见 [本地部署包](releases/linux-x86_64/2026-10-23/README.md)。

开发环境需要 Rust 1.96+、Node.js 22.19+、Python 3.10+ 与本机 ADB。Mac 本地识别需要 Swift；Linux 的纯视觉任务不依赖 Swift。以下为 Mac 源码安装步骤，其他平台与发行包见 [部署说明](docs/deployment.md)。

```sh
cd web
npm ci
npm run build
cd ..
cargo build
mkdir -p data/bin
swiftc -O scripts/ocr.swift -o data/bin/ocr
python3 scripts/install-service.py install
```

查看后台：`python3 scripts/install-service.py status`。

关闭自启和后台：`python3 scripts/install-service.py remove`。

手动运行：`cargo run`。修改代码后，重新构建并安装服务。

后台不会更改 Mac 防休眠设置。手机常亮开关默认关闭；开启时保存原设置，关闭后恢复，离线时延后处理。常亮建议接电；密码锁屏需要本人解锁。无线重连使用已登记手机的已配对服务或手动添加的连接地址；地址和端口改变后需重新填写。

## 数据与模型

- Mac 后台运行文件与数据：`~/Library/Application Support/ADB Studio/`；Linux 默认为 `~/.local/share/adb-studio/`；Windows 默认为 `%LOCALAPPDATA%\ADB Studio`；源码保留在本项目。
- 数据库、令牌、关键截图：后台目录的 `data/`；Mac 日志：`~/Library/Logs/ADB Studio/`；Linux 日志见部署说明。
- 手动开发运行的数据在本项目 `data/`，不进入 Git。命令工具通过 `data/service-root` 查找后台数据。
- 令牌文件仅当前用户可读。
- 手动清理从列表移除记录，本机归档、判断记录和截图仍保留。
- 未手动清理的记录和关键截图：保留 30 天；正在执行或等待的任务不会自动清理。
- 安装自启时，已有 `MODEL_KEY` 复制到后台目录 `.env`，仅当前用户可读；重新安装不会覆盖已有密钥。
- 更换后台密钥时编辑后台目录 `.env`；手动开发可使用环境变量、本项目或上一层 `.env`。
- macOS、Linux 与 Windows 支持纯视觉检查、页面判断与受保护点击；现有任务保持原识别方式，高频任务需另行适配。
- 默认模型：`doubao-seed-2-1-lite-260915`，Responses 接口。
- 每次运行最多 10 次模型调用；同一次疑难识别最多 2 次。工作流可以声明其他上限，最高 100 次。
- Mac／Linux 安装的后台服务监听 `0.0.0.0:17841`，局域网可通过运行电脑的 IP 访问。Windows 登录后台与开发启动默认只允许本机访问 `127.0.0.1:17841`。网页和 Agent 接口验证访问凭据并检查同源请求；手动启动可用 `ADB_STUDIO_HOST` 修改监听地址。

Agent 使用 [工作流说明](docs/workflows.md) 与 [使用技能](.agents/skills/adb-studio/SKILL.md)。网页通用组件见 [组件说明](docs/ui-components.md)。

纯视觉功能见 [识别使用说明](docs/vision-recognition.md)；多平台安装见 [部署说明](docs/deployment.md)，当前飞牛的入口与维护命令见 [飞牛原生部署](docs/feiniu-native.md)，开发与验收范围见 [方案](docs/vision-recognition-plan.md)。

## 检查

```sh
cargo test
cargo build
python3 scripts/check-mirror.py
node --experimental-strip-types scripts/check-touch.mjs
python3 scripts/check-editor.py
python3 scripts/check-integration.py
python3 scripts/check-vision.py
python3 scripts/check-platform.py
cd web
npm run check
npm run test:editor
npm run test:mirror
npm run build
```

集成、投屏与编排器检查使用临时数据库和模拟 ADB，不操作真机，分别使用端口 17842、17843、17844；正式工作台使用 17841。投屏检查前需关闭占用 17843 的开发预览。网页测试使用 Node.js 内置测试工具与 TypeScript 类型擦除，需 Node.js 22.18+ 或 24+。编排器自测范围见 [自测记录](docs/visual-workflow-editor-testing.md)。

参考项目与组件来源见 [来源声明](THIRD_PARTY_NOTICES.md)。

进入设备详情后点击“标注点击位置”：在截图弹窗点选目标，确认保存，然后在“定点点击”设置次数与间隔。标注和运行互相独立，点击任务不识别页面。各手机分别保存位置；换屏或旋转后重新标注。
