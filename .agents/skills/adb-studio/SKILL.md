# ADB 工作台

项目根目录是本技能目录向上三层。使用根目录下的 `scripts/studio.py` 调用服务，格式与接口见 [工作流说明](../../../docs/workflows.md)。

- 查询 `devices`，使用手机自身 `id`；无线地址不作为工作流绑定编号。
- 工作流版本不可覆盖。保存后即可运行，默认使用最新保存版本；不要求样本验证、试跑或另行启用。
- 以控件、文字和图片规则完成已知页面识别；模型辅助只选择允许的分支。为未知、网络阻塞、停止和完成提供明确走向。
- 纯视觉任务按 [识别说明](../../../docs/vision-recognition.md) 按需检查正反截图样本；样本检查不阻挡保存或运行；不强行迁移本地读字或高频步骤。模型结果只用于步骤声明的判断与目标。
- 利用截图与运行导出记录修正规则。通过服务接口管理任务与记录，不直接修改数据库。
- 保持步骤编号稳定、说明简短中文，让用户按网页步骤与 Agent 沟通。
- 定时滑动从当前页面开始；新应用先观察并建立该应用的页面依据。
- 运行中的任务掉线会一直等待，未启动定时任务离线则跳过。停止前查询运行编号，避免操作其他手机的任务。
- 汽水任务当前适配 iQOO 21.1.0；改到其他手机或应用版本时，先核对页面与识别规则。

本技能支持用户明确要求的任务制作、运行与托管；不授权额外任务或修改 Mac 的防休眠设置。
