# ADB 工作台前端规范

## 模块间距

- 工作台页面四周、工具栏与卡片之间、主要卡片之间使用 [全局样式](../../../web/src/app.css) 的 `--workspace-gap: 18px`。新增同级模块复用此变量，保持四周及横纵间距一致；不把卡片内部表单或按钮的小间距强行改为 18px。
- 设备右栏的滚动条占用外侧留白，不能让它额外挤开卡片。窄屏换行后仍检查卡片对齐和留白。

## 弹窗视觉

- 原生 `dialog` 和 `role="dialog"` 的弹出面板共用 [全局样式](../../../web/src/app.css) 的遮罩与外阴影：遮罩背景模糊 8px，叠加随日夜主题变化的半透明暗色；弹窗本身保持清晰，外侧使用柔和的双层阴影。调整时复用 `--dialog-backdrop`、`--dialog-backdrop-blur`、`--dialog-shadow`，不要在单个弹窗里重复定义。
- 下拉菜单与通知沿用自身样式，不添加弹窗遮罩或模糊。检查确认框、定时表单、坐标标注和编辑器弹出面板在日夜模式下的层次、文字与焦点可见性；菜单在弹窗内展开时仍应清晰可操作。具体呈现见 [网页组件说明](../../../docs/ui-components.md)。

## 下拉选择

- 页面内的单选下拉优先复用 [Dropdown](../../../web/src/lib/components/ui/dropdown/dropdown.svelte)，以设备详情的“切换手机”为外观和交互基准；不要另做原生 `<select>` 或局部菜单样式。新增需求先扩展共用组件，再在调用处配置。
- 选项使用唯一 `value`、可读 `label`；缺项提示、禁用状态、选中值、业务回调、表单校验及依赖选项变化必须保持原行为。复杂列表可用组件现有的 `selection`、`content`、`leading`、`actions` 插槽。
- 检查主页筛选与设置、设备页、定时弹窗、识别检查、工作流编辑器和标注弹窗；用鼠标及键盘验证展开、选择、关闭、焦点和边缘定位。组件弹层不得被卡片或弹窗裁切。

## 滚动条

- 所有网页滚动区域共用 [全局样式](../../../web/src/app.css) 与 [滚动监听](../../../web/src/lib/scrollbars.ts)，包括设备右栏、执行记录、编辑器面板、弹窗、下拉列表和文本输入区。
- Chromium／WebKit 的横纵滚动条统一为 4px；不支持 WebKit 滚动条样式的浏览器使用原生 `thin`。轨道和交角保持透明。
- 默认隐藏滑块。只在实际发生滚动的容器上显示；连续滚动重置计时，最后一次滚动后保留 1500ms 再隐藏。嵌套容器分别计时。
- 显隐只修改滑块颜色或透明度，不能切换滚动条宽度、`display`、`overflow` 或容器尺寸。滚动容器使用 `scrollbar-gutter: stable` 固定占位，避免内容和卡片抖动。
- 宽度与留白补偿共用 `--scrollbar-size`，不要在组件内另写滚动条尺寸。保留键盘、触控板、鼠标滚轮及原生滑块拖动。
- 在 [根布局](../../../web/src/routes/+layout.svelte) 注册一次全局监听；动态弹窗与面板复用捕获监听，卸载时清除监听和计时器。

## 验证与维护

- 网页改动运行 `npm run check` 与 `npm run build`，命令目录为项目内 `web/`。
- 在浏览器验证滚动时显示、连续滚动延长显示、停止后隐藏，以及嵌套区域独立计时；比较显隐前后的卡片位置与内容宽度，确认没有变化。
- 同时检查主页、编辑器、动态弹层及横向滚动，不以手机按键或触控操作代替网页验证。
- 只在当前仓库维护本技能，保留 Git 跟踪；不复制到用户全局技能目录，也不加入忽略规则。
